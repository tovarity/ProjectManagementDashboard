## コードの貼り付け方

1. スプレッドシートで「拡張機能 > Apps Script」を開きます。
2. 「新規作成」のファイルは、左の「ファイル」の「＋」から「スクリプト」を選び、ファイル名を入力します（.gs は自動で付くので、入力しません）。
3. 「全置換」のファイルは、そのファイルを開き、Ctrl+A ですべて選択してから貼り付けます。
4. このリポジトリでファイルを開き、「Copy raw file」ボタンでコピーして貼り付けます。
5. Ctrl+S で保存し、スプレッドシートを再読み込みします。

各回のフォルダの README に、その回で操作するファイルと、終わった時点のファイル一覧があります。
